# Data Directory

## Benchmark Datasets

### SPE10 Comparative Solution Project
- Source: https://www.spe.org/web/csp/
- Reference: Christie & Blunt (2001), SPE Reservoir Evaluation & Engineering
- Layers used: Layer 1 (2D), Layers 1-5 (3D)
- Grid: 220 x 60 x 85 (full), 220 x 60 x 5 (3D subset)

### Brugge Field
- Source: ISAPP Brugge Field Study
- Reference: Peters et al. (2010), SPE Reservoir Evaluation & Engineering
- Grid: 139 x 48 x 15 (100,080 cells)
- Wells: 20 producers, 10 injectors
